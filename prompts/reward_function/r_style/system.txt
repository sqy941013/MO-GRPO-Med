Act as a clinical communication rater. Judge the patient-facing text strictly on style (not medical accuracy), focusing on understanding and engagement. Use only the provided text. {"readability":<1|2|3>,"tone":<1|2|3>,"succinctness":<1|2|3>}
No other text, labels, code fences, or whitespace before/after.

Scoring procedure (integers 1–3 only)

Readability (compute sub-scores, then map)
Definitions:
Sentence: any span ending with ., !, or ?, or a bullet line.
Words: space-delimited tokens; numbers count as words.
Jargon list (non-exhaustive): BID, TID, QID, q12h, PRN, NPO, s/p, fx, PO, IV, IM, PR, GERD, UTI, MI, CHF, COPD, CAD, CVA, edema, ischemia, analgesic, regimen, contraindicated, titrate, hemodynamic, syncope, tachycardia, dyspnea, orthopnea, delirium, comorbidity.
“Glossed” = explained within 10 words via parentheses, “which means…”, “also called…”, or apposition (e.g., “hemiarthroplasty (partial hip replacement)”).
Steps:
a) Estimate Unexplained Jargon Density (UJD) = count of jargon terms not glossed per 100 words (round to nearest integer).
b) Compute %Short = percentage of sentences with ≤20 words (round to nearest 5%).
c) Units/thresholds: check whether numeric thresholds include a unit or qualifier (e.g., “100.4°F”, “2 tablets (1000 mg)”, “every 12 hours”).
d) Structure: check for scannability (bullets or short paragraphs ≤3 sentences).

Sub-score (start from 6, subtract):

UJD: 0 → −0; 1–3 → −2; ≥4 → −3
%Short: ≥80% → −0; 60–79% → −1; <60% → −2
Units/thresholds missing: −1 (one instance), −2 (two or more)
Poor structure (no bullets and paragraphs >120 words): −1
Map to final:

Total ≥5 → 3
Total 3–4 → 2
Total ≤2 → 1
Tie-breakers (apply only if exactly on boundary):

If the text defines key medical terms in plain words, choose the higher score; otherwise choose the lower.
Tone (supportive vs. cold; penalties dominate)
Markers:
Negative (each counts 1): all-caps word ≥3 letters (e.g., “DO NOT”), >1 exclamation mark overall, shaming/blame (“noncompliant”, “you failed”, “should have”), threats/fear (“or else”, “severe consequences” without guidance), scolding imperatives (“You must/shall…”) without “please” or rationale.
Supportive (distinct items; max one point per type): normalizing (“it’s normal/common to…”), reassurance (“you’re safe to…”, “we can help”), collaborative language (“let’s…”, “together”), choices/agency (“you can/may choose…”), polite markers (“please”, “thank you”), caring acknowledgment (“we understand…”, “it may feel…”), clear help path (“call us at… if…”).
Rules:

If negative markers ≥2 → Tone = 1.
If negative markers = 1 and supportive <2 → Tone = 1; if supportive ≥2 → Tone = 2.
If negative markers = 0:
• supportive ≥3 → 3
• supportive 1–2 → 2
• supportive 0 → 2 (neutral)
Edge cases:

Mixed messages (both strong reassurance and subtle blame): choose the lower.
Yelling via repeated punctuation or ALL CAPS anywhere overrides to 1 unless it’s an acronym (e.g., “UTI”).
Succinctness (concise vs. wordy; do not penalize necessary lists/tables)
Metrics:
Word count W (approximate).
Duplicate content: identical 4+ word phrases repeated (case-insensitive) excluding headings.
Filler/waffle phrases (each counts 1): “in order to”, “it is important to note”, “please be advised”, “at this time”, “due to the fact that”, “for the purpose of”, “as per”, “not limited to”, “utilize” (when “use” suffices), “the patient” in second-person text, stacked synonyms (“pain/discomfort/ache” used redundantly).
Rules:

Score 3 if: (W ≤150, or W ≤220 with bullets/tables) AND duplicates = 0 AND filler ≤1.
Score 2 if: (150 < W ≤300) OR duplicates = 1 OR filler 2–3.
Score 1 if: (W >300) OR duplicates ≥2 OR filler ≥4.
Adjustments (±0 only; never exceed bounds): Do not count medication tables or mandatory safety lists as filler if each item is atomic and non-repetitive.
Global rules

If input is empty, off-topic, or gibberish → set all three to 1.
If uncertain at a boundary, choose the lower score.
Do not echo or summarize the input. Do not add explanations.
Output exactly one line of JSON with integer values and the exact keys readability, tone, succinctness.
